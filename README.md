## 🎓 Пройденные темы курса (30 модулей)

- **Базовый синтаксис и конструкции:** Типы данных, циклы (`for`, `while`), списки, словари, кортежи, множества.
- **Функциональное программирование:** Лямбда-функции, List Comprehensions, декораторы (`@timer`, `@save_to_json`).
- **ООП (Объектно-Ориентированное Программирование):** Классы, наследование, инкапсуляция, переопределение методов.
- **Работа с данными и файлами:** Модуль `datetime` (ISO 8601, `strftime`), `json`, `csv`, менеджеры контекста (`with open`).
- **Сетевые запросы и API:** Библиотека `requests`, парсинг REST API (Binance API, Open-Meteo API).
- **Управление памятью:** Изменяемые и неизменяемые типы данных, работа с `id()` и оператором `is`.
- **Система контроля версий:** Git, работа с GitHub, соблюдение стандартов Conventional Commits.

## 🌤️ Выпускной проект: Weather Forecast Bot

Многофункциональный Telegram-бот для получения актуальной погоды и авто-генерации графиков на 24 часа в любом городе мира.

### ✨ Ключевые возможности бота:
- 🌍 **Всемирный поиск городов:** Находит любой населенный пункт по тексту через `geopy` (понимает сленг `Мск`, `Екб`, `Питер` и опечатки).
- 📍 **Поддержка GPS-геолокации:** Принимает геопозицию с устройства и определяет город через обратный геокодинг.
- 📊 **Инфографика в RAM:** Генерирует плавно отрисованный 24-часовой график температуры через `matplotlib` прямо в оперативной памяти (`io.BytesIO`) без создания мусорных файлов на диске.
- 🌤️ **Детализация погоды:** Расшифровка WMO-кодов с эмодзи (☀️, 🌧️, ❄️), скорость ветра и умные советы по одежде.
- 🔄 **Интерактивный UI:** Обычные клавиатуры + инлайн-кнопка `[ 🔄 Обновить ]` под графиком с обработкой `callback_query`.
- 📁 **Журналирование (CSV):** Сохранение истории вызовов (`Время`, `Имя пользователя`, `Город`, `Температура`) в формате `UTF-8`.
- 🛡️ **Надёжность и Безопасность:** Защита от падений сети (`timeout=5`, `try-except`), спрятанные токены в `.env` и чистый `.gitignore`.

## 🛠️ Используемый стек технологий

- **Язык:** Python 3.11+
- **Telegram API:** `pyTelegramBotAPI` (`telebot`)
- **Визуализация данных:** `matplotlib`
- **Геокодинг:** `geopy` (Nominatim / OpenStreetMap)
- **Сеть:** `requests` (Open-Meteo REST API)
- **Конфигурация:** `python-dotenv`
